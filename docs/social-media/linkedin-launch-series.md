# OpenCoop LinkedIn Launch Series

## Post 1 — Launch Announcement (week 1, ma)

Bij Bronsgroen hadden we nood aan een goed platform voor coöperantenbeheer. Bestaande tools waren ofwel te duur, ofwel spreadsheets die uit hun voegen barstten. Dus hebben we er zelf een gebouwd.

Vandaag stellen we OpenCoop open voor alle coöperaties.

Wat het kan:
→ Ledenregister met coöperantenportaal
→ Bankimport met automatische OGM-matching
→ Belgische fiscale berekeningen (roerende voorheffing)
→ Elke coöperatie krijgt haar eigen omgeving
→ Te gebruiken als SaaS of self-hosted

De code is opensource (AGPL). Prijzen en een live demo op opencoop.be.

## Post 2 — Ledenregister & portaal (week 1, do)

Een coöperatie met 200 leden beheren vanuit een spreadsheet? Het kan. Tot iemand per ongeluk een rij overschrijft.

OpenCoop geeft elke coöperatie een digitaal ledenregister met:

→ Individuele leden, bedrijven en minderjarigen
→ Een persoonlijk portaal waar coöperanten hun participatie, dividenden en documenten raadplegen
→ Online registratie met EPC QR-code voor vlotte betaling
→ Meerdere aandelenklassen met eigen prijzen en stemrechten

Geen Excel meer. Geen vergissingen meer.

Probeer de demo op opencoop.be/demo

#coöperatie #ledenregistratie #digitalisering

## Post 3 — Bankimport & OGM-matching (week 2, ma)

Elke maand bankafschriften downloaden, OGM-codes handmatig matchen met inschrijvingen, en hopen dat er geen tikfout in zit.

Herkenbaar?

OpenCoop automatiseert dit volledig:

→ Koppel je bankrekening via Ponto Connect (PSD2)
→ Inkomende betalingen worden automatisch gematcht aan inschrijvingen via OGM-codes
→ Bij een match wordt de transactie automatisch afgerond
→ Geen handmatig werk meer, geen fouten meer

Van bankafschrift tot bevestiging — zonder tussenkomst.

Bekijk hoe het werkt op opencoop.be

#coöperatie #bankautomatisering #PSD2 #openbanking

## Post 4 — Dividenden & fiscaliteit (week 2, do)

Dividenden uitkeren aan coöperanten klinkt eenvoudig. Tot je de roerende voorheffing moet berekenen per aandeelhouder, per aandelenklasse, met verschillende tarieven.

OpenCoop doet het rekenwerk:

→ Automatische berekening van bruto dividend, roerende voorheffing en netto uitkering
→ Per coöperant een overzichtelijk dividendattest (PDF)
→ Jaaroverzicht met fiscale rapportage
→ Ondersteuning voor meerdere dividendperiodes

Belgische fiscaliteit, correct afgehandeld. Zonder spreadsheet-acrobatiek.

Meer info op opencoop.be

#coöperatie #dividenden #roerendevoorheffing #compliance

## Post 5 — Open source & self-hosted (week 3, ma)

OpenCoop is opensource. Niet als marketingterm, maar als overtuiging.

Coöperaties zijn gebouwd op transparantie en gedeeld eigenaarschap. De software die ze gebruiken zou dat ook moeten zijn.

→ Volledige broncode beschikbaar (AGPL-3.0)
→ Self-hosting mogelijk — jouw data, jouw servers
→ Of gebruik het als SaaS zonder technische setup
→ Mee ontwikkelen of aanpassen? Pull requests zijn welkom

We geloven dat coöperatieve software ook coöperatief mag zijn.

GitHub: github.com/opencoophq/opencoop

## Post 6 — Messaging (week 3, do)

Communicatie met coöperanten verloopt vaak via losse e-mails, nieuwsbrieven of — eerlijk — helemaal niet.

Met de nieuwe messaging-functie in OpenCoop krijgt elke coöperatie een ingebouwde inbox:

→ Berichten aan individuele coöperanten of broadcasts aan iedereen
→ Coöperanten kunnen rechtstreeks antwoorden
→ Bestanden bijvoegen
→ E-mailnotificatie bij nieuwe berichten

Eén plek voor alle communicatie met je leden. Geen losse e-mailthreads meer.

Probeer het uit op opencoop.be/demo
